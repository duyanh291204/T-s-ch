HƯỚNG DẪN CÀI ĐẶT TỦ SÁCH LÊN IPHONE (KHÔNG CẦN BIẾT CODE — 5 PHÚT XONG)
=========================================================================

Trong thư mục vừa giải nén đã có đủ mọi thứ (web app, icon iPhone, bot tự kéo tin 4 NXB Trẻ / Kim Đồng / IPM / Nhã Nam). Ông chỉ cần làm đúng 5 bước bấm chuột sau:

BƯỚC 1: TẠO KHO CHỨA MIỄN PHÍ TRÊN GITHUB
1. Vào https://github.com và đăng nhập (hoặc đăng ký miễn phí bằng Gmail).
2. Bấm dấu "+" góc trên bên phải -> chọn "New repository".
3. Ô "Repository name" gõ: tu-sach
4. Chọn chế độ "Public" (bắt buộc chọn Public thì mới dùng web miễn phí).
5. Bấm nút xanh "Create repository".

BƯỚC 2: THẢ TOÀN BỘ FILE LÊN
1. Ở màn hình vừa tạo, bấm dòng chữ nhỏ "uploading an existing file".
2. Kéo toàn bộ các file vừa giải nén (index.html, manifest.json, news.json, apple-touch-icon.png, icon-512.png, scraper.py, requirements.txt) thả vào khung trình duyệt.
3. Bấm nút xanh "Commit changes".

* LƯU Ý QUAN TRỌNG CHO THƯ MỤC ẨN ".github":
Trên Mac hoặc Windows nhiều lúc kéo-thả sẽ ẩn mất thư mục ".github". Nếu nhìn trên trang chính repo GitHub chưa thấy thư mục ".github", làm nhanh trong 20 giây:
- Bấm nút "Add file" -> "Create new file".
- Ô đặt tên file gõ chính xác: .github/workflows/update-news.yml
- Mở file update-news.yml (trong thư mục .github/workflows ở máy) bằng Notepad/TextEdit, copy toàn bộ dán sang, rồi bấm "Commit changes".

BƯỚC 3: BẬT LINK WEB (GITHUB PAGES)
1. Trên trang repo "tu-sach", bấm tab "Settings" (hình bánh răng ở trên cùng).
2. Nhìn cột bên trái chọn "Pages".
3. Ở mục "Branch", đổi từ "None" sang "main", giữ nguyên "/ (root)" rồi bấm "Save".
4. Chờ khoảng 1 phút rồi tải lại trang đó -> sẽ hiện link web của riêng ông:
   https://<tên-github-của-ông>.github.io/tu-sach/

BƯỚC 4: BẬT BOT TỰ CẬP NHẬT TIN 4 NXB (MIỄN PHÍ)
(Không cần làm bước key cũng được — bot vẫn tự cào 4 web Trẻ, Kim Đồng, IPM, Nhã Nam. Nhưng gắn thêm 2 key miễn phí dưới đây thì AI lọc tin siêu sạch và cào thêm được FB, IG, TikTok):
1. Vào tab "Settings" -> cột trái chọn "Secrets and variables" -> "Actions" -> nút xanh "New repository secret".
2. Secret 1 (Lọc tin rác bằng AI - Khuyên dùng):
   - Lấy key miễn phí ở https://aistudio.google.com/apikey
   - Name: GEMINI_API_KEY
   - Secret: dán key vừa lấy -> bấm Add secret.
3. Secret 2 (Cào thêm Facebook, Instagram, TikTok - Tuỳ chọn):
   - Đăng ký gói Free ($5/tháng miễn phí) ở https://apify.com -> vào Settings -> API & Integrations copy Personal API token.
   - Name: APIFY_TOKEN
   - Secret: dán token -> bấm Add secret.
4. Chạy thử lần đầu:
   - Bấm tab "Actions" ở thanh trên cùng của GitHub.
   - Chọn "Cap nhat tin 4 NXB" ở cột trái -> bấm nút "Run workflow" -> bấm nút xanh "Run workflow".
   - Đợi ~1 phút hiện dấu tích xanh là xong! Từ giờ ngày 4 lần (7h30, 11h30, 16h30, 20h30) bot tự chạy ngầm, không cần đụng tay nữa.

BƯỚC 5: ĐƯA THÀNH APP TRÊN IPHONE
1. Mở link https://<tên-github-của-ông>.github.io/tu-sach/ bằng Safari trên iPhone.
2. Bấm nút Chia sẻ (ô vuông có mũi tên hướng lên ở thanh dưới cùng).
3. Cuộn xuống chọn "Thêm vào MH chính" (Add to Home Screen) -> bấm "Thêm".
4. Xong! Icon Tủ Sách nằm ngay màn hình chính như app gốc, mở lên là tin mới 4 NXB tự đổ về.

MẸO NHỎ KHI DÙNG LÂU DÀI:
- Dữ liệu tủ sách của ông lưu trực tiếp trên iPhone (riêng tư 100%, không ai xem được).
- Thỉnh thoảng (khoảng 1 tháng/lần) bấm nút bánh răng góc trên phải trong app -> "Xuất file sao lưu (.json)" lưu vào iCloud Drive phòng khi đổi điện thoại mới.
